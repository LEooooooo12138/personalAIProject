日期：2026-10-10。实施基线：`84b5ebba90964857a4986f1055a2bc1f599aec17`。实现与自动化验收结果见下表；系统文字缩放、完整读屏、真实硬件和供应商验证单列为未验证。

## 实施结果与边界

组件库、应用外壳、认证界面及全部12个业务页面已迁移。保留家序品牌、中文、浅色绿系、原路由/URL参数、请求层、身份代次、业务Hook和后端规则。没有新增UI、图表、状态管理或测试依赖。可靠性变化限于R1–R5，以及批准的录音计时与过期期限锁定。

新基础入口为 `go-agent/web/src/ui/index.ts` 与 `ui/ui.css`。UI不读取认证、API或业务状态。开发目录由 `npm run ui:catalog` 提供，只用模拟数据，生产构建不输出展示页。使用指南：[组件库](component-library.md)。

旧 `styles.css`、`console.css`、`pages/chat.css`、迁移 `legacy.css`、LegacyPageBoundary及旧icons入口全部退出。最终层顺序为reset/tokens/ui/layout/features。页面通过原生语义、状态图标与明确标签、指标、步骤、可信进度及规则关系呈现任务；正文、错误原因、权限和云端说明保留必要文字。

## 五项可靠性修复

| 项目 | 实现和证据 |
| --- | --- |
| R1请求取消/身份切换 | 每请求独立取消/截止时间；普通请求与Cookie串行通道分开。保持Worker URL/名称，协议v2。可选expected-user头与已有CSRF防止旧请求携新Cookie回填。迟到Cookie、ACK失败和CONNECTING离页租约均有VM及业务回归；不能证明关闭时安全失败。 |
| R2会话换轮 | 新SID只保留当前问答，服务端消息索引用于手动/自动朗读；真实fixture超过20轮后恢复为两条消息。 |
| R3控制结果查询 | 执行中只读、有界GET刷新，隐藏暂停/可见恢复，60秒停止并可明确刷新。历史恢复、自动轮询、手动刷新共用页面局部读取队列，真实未结算GET最多2，同ID不并发。unknown不自动重复写入。 |
| R4状态语义 | 后端仅投影可选domain/device_class/unit，复用共享formatter；门磁、开关、未知二值和数字单位分别验证，不按名字猜业务。旧DTO兼容。 |
| R5成员弹窗竞态 | 操作代次、身份、成员、弹窗类型与挂载状态校验；等待时不关闭/换成员。临时口令只归当前操作，关闭/身份离开清空；晚回应不显示到新页面。 |

期限已判过期后不会因时钟回拨重新启用。录音从实际开始计时，60秒停到ready，不能自动发送；换SID/身份/卸载清理。识别与朗读模式分别展示，自动朗读默认关闭，合成音轨的真实MediaRecorder/WAV浏览器用例保持未发送文字草稿。

## 八荣八耻落实与实施裁定

查证现有Go handlers/验证器后实现；以批准规格为目标；复用认证、请求、业务Hook、SafeMarkdown与SVG；没有推断未知占用/传感器/进度；可靠性先补失败回归再修复；互斥文件所有权与交叉审查分步推进；报告只列实际验证。

首页摘要原先拥有查询Hook，继续保留该所有权，而未按任务文字搬入HomePage。页面组合样式集中在presentation.css，知识/家庭/助手/聊天各有局部样式，不重复基础控件。全页提议读取的小队列仅限同一业务读取，不引入新store或迁移状态。工作区为原生管理的隔离worktree。

先前审查曾记录go-run退出挂起；本轮用原启动方式跑errors回归自然退出，未再次复现，不能断言原因。现改独立binary；每文件真实退出/端口检查及自有临时目录清理提供新证据。Windows取消的进程树结束不代表Go defer执行，临时数据由runner在结束证据后删除。

实现保存在隔离工作区`仓库根目录`，分支`codex/component-library-reset`；仅创建本地提交，没有合并或推送。

- 真实麦克风音质、真实TTS/ASR/MiMo供应商、付费服务、真实物理负载、长期HA续期和断网未执行。浏览器录音用生成音轨，底层录制/转WAV是真实实现。
- 构建仍给出既有500kB主包提示；不为此改变前端架构，未以包大小推断加载耗时。

## 2026-10-11 模型接线验证边界补充

离线 fixture 的固定回复与模拟语音不能证明真实模型或供应商可用。后续增加了生产 Bootstrap、认证、CSRF、助手设置与 WebSocket 的上游契约回归，覆盖本地与云端会话模式固定、请求参数及隐私来源标记。该契约使用受控上游及测试凭据。

本机部署、真实模型调用和浏览器现场证据保留在私有运行记录中。公开文档不据此声明当前服务状态，也不把离线 E2E 或契约测试升级为真实云端和语音供应商验收。
