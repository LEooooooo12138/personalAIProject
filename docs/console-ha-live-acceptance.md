## 授权与范围

用户允许以书房灯或任意开关作为测试条件，其他设备不作为真实测试对象。HA 目录未发现明确命名为书房灯的独立实体，因此只启用一个书房登记开关通道，显示为“书房进门开关1（授权通道测试）”。它对应哪盏灯及下游负载所在房间仍未核验。

本地精确目标配置仅允许 `turn_on` / `turn_off`，保留 `load_location_verified: false`，增加 `switch_test_authorized: true`。这一标记默认关闭，仅适用于精确 `switch` 实体；不扩大其他实体权限，也不跳过管理员鉴权、独立确认、到期检查或回读。真实 entity_id 和运行凭据仅保留在受保护本地配置中，不提交到仓库。

## 登录后验收步骤及结果

1. 在“对话”发送 `查询书房进门开关1的当前状态`，记录原始 on/off 状态及观察时间。
2. 发送相反动作，例如原状态关闭则发送 `打开书房进门开关1`。核对提议名称、登记区域、动作和确认按钮。
3. 点击该卡片的“确认打开”或“确认关闭”，等待“已观察到目标状态”和带时间的回读结果。
4. 通过新聊天提议及确认，将同一通道恢复到原始状态；再次回读，记录恢复结果。
5. 若结果为未知，只点“核对状态”，不重复发送原动作。刷新历史卡片应显示服务端当前记录。
